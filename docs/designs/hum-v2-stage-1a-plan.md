# Hum v2 stage 1a: engineering plan

Generated by /plan-eng-review on 2026-10-03. Branch: `hum-v2`. Sources: [hum-v2-world-story.md](hum-v2-world-story.md) (APPROVED) and [DESIGN.md](../../DESIGN.md) v2 "Lights at Night".

## Slicing (D1)
The work is done in order on `hum-v2`. Each step passes typecheck, unit tests and build. Before the single merge to `main`, the branch is deployed to a Cloudflare preview URL and QA'd on a real phone.

```
T0 SOURCE   checked quotes + Ember rows (gate: video/grid highs re-sourced, IEA 2030 range found)
T1 DATA     series (electricity + CO2 per year) + countries + validation + How We Know tables  (v1 page still works)
T2 REMOVE   v1 scene/quiz/k/guardrails/copy/posters/sound/codec; old fonts out; tokens regenerated
T3 PRESENT  format.ts + charts (scale, race, fan) with tests
T4 PAGE     generated hero + slider + Play + fallback; Instrument Serif in; fonts preloaded
T5 CALC     engine.weeklyUse(counts) + calculator section
T8 STORY    "AI inside" headline bars, "Where does the electricity go?", measured impact rows
T7 SHIP     E2E + a11y + budget + Lighthouse green ─► preview deploy + phone QA ─► merge to main
```

## Architecture

```
data/sources/                      build:data (scripts/)                       generated + served
 constants.source.json ─┐
 series.source.json ────┼─► validate (schema.ts) ─► buildSeries() ─────────► public/data/series.json
 countries.source.json ─┘        │                  [lib/series.ts]            years 2017–2035 × {electricity, co2}
 hubs.source.json (stage 2)      │                                              each {mid, lo, hi, kind, rule}; water: today only
                                 ├─► check-countries (CI: download CSV, verify sha256, diff rows)
                                 ├─► renderHero() ──────────────────────────► src/hero.generated.html   (CI diff-checked)
                                 └─► renderHowWeKnow() ─────────────────────► src/how/content.generated.html
vite plugin: inline *.generated.html into index.html / how-we-know.html (existing pattern)

browser:  main.ts ─► fetch series.json ─► slider / Play ─► charts/race + charts/fan (same pure fns as build)
                                       └► calculator ─► engine.weeklyUse(counts)
          on load: strip any v1 #w1 hash (replaceState) + remove localStorage hum.world
```

### Decisions
- **T0 sourcing gate (outside #1).** Before T1, these need checked quotes:
  - the IEA 2030 sensitivity range, stated as *consumption*, not generation (press mixes 415 consumption with 460 generation)
  - the 2035 CO2 low (High-Efficiency case)
  - the Ember country rows
  - re-sourced video-clip and grid-carbon highs (today mid = high from one source)

  Stage 1a cannot ship until the video and grid highs are re-sourced.
- **D2 / 1A: build-time series, now multi-metric (outside #2).**
  - `buildSeries()` is pure and writes `series.json`. Each year from 2017 to 2035 holds electricity and CO2 as `{mid, lo, hi}`, tagged `published` or `derived` with the rule used.
  - Water is today-only; past 2025 it shows "no projection published".
  - **Crossing years ("passes X") (outside #3):** computed against published points where possible. When a crossing depends on interpolated band edges, it is tagged `derived` and drawn dashed or labelled "calculated". A test enforces this.
- **D3 / 2A + outside #9: countries.**
  - The `checked: 'dataset'` source kind holds the dataset name, version, https URL and the CSV's sha256.
  - About 12 filtered rows are committed in `countries.source.json`.
  - A CI job downloads the CSV, checks the hash and diffs the rows. If Ember republishes the file, the hash fails the job on purpose, forcing an explicit data update. Pin a versioned URL if Ember offers one.
- **D4 / 3A + outside #6: pre-built hero.** `build:data` writes `src/hero.generated.html` (headline range reading, today's race, no-JS table). The existing plugin inlines it, and CI's generated-files diff covers it. If `series.json` fails to load, the pre-built hero stays and the slider is disabled with a note.
- **D5 / 4A (outside #5; reverses the earlier 4B): old links.** The v1 share codec is deleted. On load, any `#w1.` hash is removed and `hum.world` is cleared, then the normal page shows.
- **D6 / 5A (outside #4; reverses the earlier 5B): sound.** Stage 1a ships without sound: the sound module, button and v1 soundscape are removed. "The hum" moves to stage 1b. It can be rebuilt from git history (today's Web Audio engine and its measured-audio tests).
- **Outside #7: two changes recorded in the design doc.**
  - The page opens at the latest measured year with a "Play 2017 to 2035" button; there is no autoplay on load.
  - The v1 Earth posters are removed, because the pre-built hero is the first screen.

## Code quality
- **D7 / 6A:** `src/present/format.ts` owns rounding, grouping, units and the range-reading HTML. It replaces `num`, `round` and `grouped`.
- **D8 / 7A:** `weeklyUse({questionsPerDay, picturesPerWeek, videosPerWeek}, c, level)`.
  - Removed: plan, "lighter AI", health, animals, kidComparisons, the guardrails, `mapping.json` and `derive:k`.
  - The quiz table leaves `constants.source.json`; nothing needs it now.
- **D9 / 8A:** `src/charts/{scale,race,fan}.ts` are pure functions that return SVG/HTML strings.
  - Classes `.derived`, `.forecast` and `.band` encode the honesty rules.
  - Rows are keyed and reordered with transforms (350ms).
- **Outside #10:** the work runs in sequence. T2 removes the `@fontsource/grandstander`/`shantell-sans` packages; T4 adds `instrument-serif` and the Atkinson Mono package.

## Performance
- **D10 / 9A:** Instrument Serif 400 latin is self-hosted and preloaded, with a size-adjusted Georgia fallback. Atkinson Next and Mono load normally.
- **Budget:** first-screen JS stays at or under 90 KB gzipped with no three.js. Lighthouse: LCP at most 2.5 s, CLS at most 0.1.

## Tests (all required)
- **Unit:**
  - `series.test.ts`: published points, the 2025 derivation, back-calculation, interpolation, CO2 alongside electricity, the band, "no published low", ordering invariants, and crossings tagged derived when interpolated.
  - Schema tests for series, countries and the `dataset` kind.
  - `check-countries.test.ts` against a fixture CSV: match, mismatch, hash mismatch, missing row.
  - `format.test.ts`.
  - `charts/*.test.ts`: ticks; crossings early, late, never and already; classes; long names.
  - `engine.test.ts` with counts: 0, max, video share.
  - A legacy-cleanup unit test: hash stripped and storage cleared.
- **E2E:**
  - `hero.spec.ts`:
    - with JS off, the headline and table are present
    - the page opens at the latest measured year
    - the drag updates the caption and `aria-valuetext`
    - arrow keys step one year
    - Play and Pause work
    - under reduced motion, Play jumps to 2035
    - a `series.json` 404 leaves the slider disabled with a note
  - `calculator.spec.ts`: outputs update, and an old `#w1.` link opens the clean page with storage cleared.
  - `story.spec.ts`: the AI-inside bars, "where it goes" and the impact rows render with badges.
  - `a11y.spec.ts`: axe on the page and How We Know.
  - Kept: `layout.spec.ts` (tables fit at 320/390) and `targets.spec.ts` (44px).
- **Removed with v1:** the journey, history, keyboard, world-layout and sound specs; the guardrail, dive, state, world, mix and codec unit tests.

## Failure modes
| Path | Realistic failure | Test | Handling | User sees |
|---|---|---|---|---|
| series.json fetch | 404 / slow network | hero.spec 404 | pre-built hero, slider disabled | clear note |
| buildSeries | new figure breaks order (lo > mid) | series invariants | build fails | nothing ships |
| crossing years | rests on interpolated edges | series/charts tests | tagged derived | "calculated" label |
| countries | Ember republishes the CSV / typo | check-countries in CI | job fails | nothing ships |
| old v1 link | `#w1.` hash or stored world | calculator.spec | stripped and cleared | normal page |
| fonts | font file fails | Lighthouse CLS | matched fallback | stable headline |

No critical gaps.

### Notes from building T0–T1 (2026-10-03)
- **Where the series logic lives:** `src/footprint/series.ts`, not `scripts/lib/series.ts`, because the browser also needs the crossing calculation. `scripts/lib/build.ts` only wraps it (validate, hash, write).
- **The countries check runs as its own CI job (`source-data`):** it goes red when Ember re-publishes the file, but deploy depends only on `test`, so an unrelated fix can still ship.
- **DESIGN.md v2 is parked:** it sits at `docs/designs/DESIGN-v2.md` until T2, so the token check stays green while the v1 scene still reads the clay colours. T2 moves it back to `DESIGN.md` and regenerates the tokens.
